#Описание проекта

Search Engine — это программа, которая индексирует набор текстовых файлов и позволяет искать по ним документы, содержащие все слова из поискового запроса. Результаты поиска ранжируются по релевантности и сохраняются в JSON-файл.
Основные возможности
* Чтение конфигурации и списка файлов для индексации из config.json
* Обработка поисковых запросов из requests.json
* Построение инвертированного индекса для быстрого поиска
* Ранжирование документов по релевантности (TF-IDF подход)
* Сохранение результатов в answers.json
* Многопоточная индексация документов
* Обработка ошибок (отсутствие файлов, неверный формат конфигурации)
Стек технологий
* Язык программирования: C++17
* Сборка: CMake (версия 3.10+)
* Работа с JSON: nlohmann/json (v3.11.2)
* Тестирование: Google Test (GTest)
* Компиляторы: Поддерживаются GCC, MinGW, MSVC
* Параллелизм: Многопоточная индексация (std::thread)

Форматы файлов
config.json
json
{
    "config": {
        "name": "SearchEngine",
        "version": "0.1",
        "max_responses": 5
    },
    "files": [
        "resources/file001.txt",
        "resources/file002.txt"
    ]
}
requests.json
json
{
    "requests": [
        "milk sugar",
        "london capital",
        "nonexistent word"
    ]
}
answers.json (пример результата)
json
{
    "answers": {
        "request001": {
            "result": "true",
            "relevance": [
                {"docid": 2, "rank": 1.0},
                {"docid": 0, "rank": 0.7},
                {"docid": 1, "rank": 0.3}
            ]
        },
        "request002": {
            "result": "true",
            "relevance": [
                {"docid": 7, "rank": 1.0}
            ]
        },
        "request003": {
            "result": "false"
        }
    }
}


Алгоритм работы
1. Инициализация: Загрузка конфигурации из config.json
2. Индексация:
o Чтение документов из указанных файлов
o Разбиение на слова (только строчные латинские буквы)
o Построение инвертированного индекса (слово ? список документов с частотой)
o Многопоточная обработка файлов
3. Обработка запросов:
o Чтение запросов из requests.json
o Для каждого запроса поиск документов, содержащих все слова
o Расчёт абсолютной релевантности (сумма частот слов)
o Нормализация релевантности (деление на максимум)
o Сортировка по убыванию релевантности
4. Сохранение результатов в answers.json


Установка и запуск
Требования
* CMake 3.10 или выше
* Компилятор с поддержкой C++17 (GCC 7+, MinGW, MSVC 2019+)
* Git (для клонирования репозитория)
Инструкция по сборке
1. Клонировать репозиторий
bash
git clone https://github.com/RenatUfa/SearchEngine.git
cd search_engine
2. Создать директорию для сборки
bash
mkdir build
cd build
3. Собрать проект
bash
cmake ..
cmake --build . --config Release
4. Запустить программу
bash
# Из директории build
./search_engine
Или скопировать исполняемый файл в корневую директорию проекта:
bash
cp search_engine ../
cd ..
./search_engine
Настройка перед запуском
1. Создайте файл config.json в корне проекта (см. пример выше)
2. Создайте файл requests.json с поисковыми запросами
3. Подготовьте текстовые файлы с документами (пути указаны в config.json)
4. Убедитесь, что все файлы существуют (программа выведет предупреждения для отсутствующих)
Запуск тестов
bash
# Из директории build
ctest
# или запустить конкретный тест
./search_engine_tests


Тестирование
Проект покрыт модульными тестами с использованием Google Test:
* Тестирование инвертированного индекса: проверка корректности подсчёта частот слов
* Тестирование поиска: проверка ранжирования и сортировки результатов
* Тестирование граничных случаев: отсутствие слов, пустые запросы
